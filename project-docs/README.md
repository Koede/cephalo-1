# Project docs

Copies of the docs that lived only in the claude.ai Project "Octopus Drone" (design notes under `claude/`, code under
`claude/code/`), moved here so the Project can be cleared. Paths match the Project's paths exactly.

These files were copied by reading each doc and writing it back out, not by a byte-for-byte download. Where possible
each batch was checked by running its code (for example, `claude/code/hippos/legs_v3/legs_v3_study.py` reproduces the
numbers in `claude/hippos1-legs-v3.md`). Many scripts import modules that sit in `cephalo2/` or in other folders of the
original workspace, so not every script runs from here as it stands.

Docs that already had an identical copy in `cephalo2/` are not repeated here.
